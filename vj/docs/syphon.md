# Syphon in VJ

VJ supports native Syphon sources, and embedded Patch can publish video outputs through Syphon. Typed Patch collection and graph effects are consumed directly by VJ. See [Patch integration](../native-app/parity/PATCH.md) and [engine inputs](../native-app/parity/ENGINE_INPUTS_AND_COLLECTIONS.md).

The former browser/Python application documentation is preserved on `archive/web-vj-2026-10-12`.
